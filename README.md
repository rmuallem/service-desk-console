# IT Service Desk Console

An interactive web-based IT Helpdesk Dashboard for managing IT incidents and service requests.

**Live Demo:** https://rmuallem.github.io/service-desk-console/

## Project Overview

This project demonstrates a browser-based IT ticket management system.

It includes realistic IT support scenarios related to enterprise networking, Microsoft 365, Windows Server, identity management, and hardware troubleshooting.

The application was created as a learning project with AI assistance and published using GitHub Pages.

## Features

- Create, update, and delete IT support tickets
- Manage ticket priorities: Critical, High, Medium, Low
- Track ticket status: Open, In Progress, Resolved
- Assign tickets to technicians
- Monitor SLA deadlines
- View ticket statistics and dashboard charts
- Search, filter, and sort tickets
- Add troubleshooting notes and track activity history
- Save tickets locally using browser localStorage
- Load realistic sample IT incidents

## How to Use

1. Open the Live Demo.
2. Click **New ticket**.
3. Enter the incident details.
4. Select the category and priority.
5. Create the ticket.
6. Update its status and add troubleshooting notes.
7. Refresh the page to verify local data persistence.

## Architecture

The application is built as a standalone HTML file containing HTML, CSS, and JavaScript.

It runs directly in the browser without a backend server or external database.

Ticket data is stored locally using localStorage.

**Limitations:** Data is not shared between users or devices. The application is a demonstration prototype, not a production-ready ITSM system.
